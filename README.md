# Abdelrahman Sadek Portfolio

Responsive one-page portfolio website focused on Flutter and mobile-development roles.

## Connected profiles
- LinkedIn: https://www.linkedin.com/in/abdelrahman-sadek74
- GitHub: https://github.com/abdelrahmansadek225

## Design choice
Project cards intentionally use no screenshots or individual logos. Each project is presented with:
- Project name
- Role
- Concise description
- Technology stack

This keeps the site lightweight, clean, and recruiter-focused.
